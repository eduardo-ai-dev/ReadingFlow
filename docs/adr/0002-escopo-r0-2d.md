# Escopo R0 estritamente em 2D com 3D opcional no R1

O Release R0 entrega toda a biblioteca pessoal em interfaces 2D responsivas (lista e grade) renderizadas com Server Components, sem incluir Three.js ou React Three Fiber no pacote inicial. Isso valida primeiro a ativação, o cadastro por ISBN/importação e o acompanhamento de leitura, garantindo desempenho em celulares de entrada e mantendo o 3D do R1 como uma camada puramente visual sobre a mesma fonte da verdade.
